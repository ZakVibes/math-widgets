This device can't run the GPU simulator, so the map is computed on the CPU at lower resolution. Chaos and Live angles are unavailable.

The map is a 2D slice through all possible starts. Angles: each pixel is a pair of starting angles, with both momenta fixed above (zero means released from rest). Momenta: each pixel is a pair of starting kicks p₁, p₂ (in m·l·√(g·l)), with both angles fixed above (zero means hanging straight down). The map runs on your GPU and adjusts its pace to keep taps, pinches and scrolling smooth. Flip-time mode stops simulating pendulums once their color is final, so switching to Live angles restarts the run. On a phone, 300–400 px is a good balance.
