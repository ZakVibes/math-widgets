Rational map explorer: zn + c / zm

The parameter plane (c) shows where the critical orbit stays bounded; the dynamical plane (z) shows the dynamics for the c you pick. Tap the parameter plane or drag its marker to set c. On both panels, drag to pan and pinch or scroll to zoom; double-tap or double-click the dynamical plane to reset it. Try n = 2, m = 3 and a small c. Set m = 0 for the ordinary zn + c (Mandelbrot and Julia sets). Both panels zoom far beyond normal precision (the zoom label shows "deep"); deep views usually need more iterations. Animate c moves the marker around the centre of the parameter plane view; Path sets the shape of the loop.
